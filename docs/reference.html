There are no implicit numeric conversions. Integer addition, subtraction, and multiplication trap on overflow. Use Wrapping_Add, Wrapping_Sub, or Wrapping_Mul when fixed-width wraparound is intentional. Declared locals start zeroed.

Volatile access

Registers are read and written with width-specific intrinsics that the optimizer will not reorder or remove.

Value = Vol_Read_32(0x40014000)
Vol_Write_32(0x40014000, Value | 1)

Programmable I/O (PIO) DSL Syntax

Loom provides a native DSL for the RP2040 Programmable I/O (PIO) state machines. Programs compile directly into 16-bit PIO instructions:

Pio_Program Ws2812_Blink
    Wrap_Target
    Loop_Start:
        Pull(Block) [1]
        Out(Pins, 1) [2]
        Set(Pins, 0) [1]
    Wrap
End Pio_Program

Available PIO instructions: Set, Wrap_Target, Wrap, Pull, Push, Out, In, Mov, Jmp, Wait, Irq, and side-set Side with cycle delays [cycles].
