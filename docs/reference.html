Technical Language Specification

Loom 1.0.0 language reference

The authoritative specification of Loom v1.1.0: type system, literal forms, keyword directory, operator precedence, volatile memory intrinsics, compiler diagnostics, CLI options, and formal EBNF grammar.

Complete keyword directory

Loom enforces strict case-sensitivity. Keywords are strictly capitalized, with only three reserved lowercase tokens (while, until, use):

KeywordCategorySyntax Pattern & Description
ModuleStructureModule <Name> — First line of every source file.
BlockStructureBlock <Name> ... End <Name> — Defines an executable procedure or function.
GlobalStructureBlock Global ... End Global — Declares global variables and constants.
TakesHeaderTakes <Name> : <Type> — Declares parameter list for a block.
ProducesHeaderProduces <Type> or concise Produces (<Expr>) — Declares return type or concise return expression.
DeclaresHeaderDeclares <Name> : <Type> [= <Init>] — Declares local variable block.
ImplementsHeaderImplements — Begins block statement execution body.
EndStructureEnd <Name> / End If / End Loop / End Match — Closes a block or control structure.
GiveControlGive <Expr> — Returns a value from a value-producing block.
If / Else If / ElseControlIf <Cond> ... Else If <Cond> ... Else ... End If — Conditional branching.
LoopControlLoop ... End Loop, Loop while <Cond>, or Loop until <Cond> — Loop execution.
ExitControlExit — Terminates the nearest enclosing loop or exits a procedure early.
SkipControlSkip — Advances immediately to the next loop iteration check.
Match / WhenControlMatch <Expr> When <Pattern>: ... Else: ... End Match — Pattern matching.
EnsureMemoryEnsure { <Statement> } — Schedules deterministic LIFO cleanup on block exit.
AddressMemoryAddress(<Var>) — Returns T Pointer to an lvalue variable.
DerefMemoryDeref(<Ptr>) — Dereferences a pointer for read or assignment (Deref(P) = 42).
CastTypeCast[<Target_Type>](<Expr>) — Explicit type conversion with narrowing diagnostics.
SliceTypeSlice(<Arr>) or Slice(<Ptr>, <Len>) — Constructs a fat pointer slice.
RecordTypeRecord <Name> ... End <Name> — Defines a composite struct type.
EnumTypeEnum <Name> : <Type> ... End <Name> — Defines an enumerated type with explicit underlying scalar.
ConstantType<Name> : Constant <Type> = <Value> — Compile-time immutable constant.
ExternInteropExtern Block <Name> ... End <Name> — Declares a C ABI foreign function.
ImportModuleImport <Module> — Imports an external source file or SDK module.
useModuleuse <Module> — Unqualified namespace import (file-level or block-scoped).

Direct Block Invocations: Loom does not have a Call keyword. Procedures and functions are called directly by their identifier: My_Procedure() or Result = My_Function(Arg). The compiler emits diagnostic E1001 if Call is erroneously used.

Operator precedence & compound assignments

Binary operators associate left to right. Precedence is organized into 10 descending levels:

Precedence LevelOperatorsCategory & Behavior
1 (Highest)- (unary), Not, ~ (bitwise NOT)Unary negation, logical inversion, and bitwise NOT.
2*, /, Mod, %Multiplication, integer/float division, and modulo / remainder.
3+, -Addition and subtraction. Fixed integer overflow wraps.
4LSL, LSRLogical Shift Left and Shift Right (sign-extended for signed types).
5==, !=, <, <=, >, >=Relational equality and ordering comparisons. Evaluates to Boolean.
6&Bitwise AND.
7^Bitwise XOR.
8|Bitwise OR.
9AndLogical AND.
10 (Lowest)OrLogical OR.

Compound Assignment Operators

Loom provides in-place mutating assignment operators: +=, -=, *=, /=, &=, |=, and ^=:

Total += Value     # Equivalent to: Total = Total + Value
Mask  &= ~0x04     # Equivalent to: Mask = Mask & ~0x04
Flags |= 0x80      # Equivalent to: Flags = Flags | 0x80
Bits  ^= 0xFF      # Equivalent to: Bits = Bits ^ 0xFF

Volatile memory intrinsics

Hardware registers, memory-mapped I/O (MMIO), and DMA control buffers must be accessed using volatile intrinsics that prevent the compiler from optimizing, reordering, or caching accesses:

Access WidthVolatile Read FunctionVolatile Write Function
8-Bit (Byte)Vol_Read_8(Address : Signed_64) : Unsigned_8Vol_Write_8(Address : Signed_64, Value : Unsigned_8)
16-Bit (Half-Word)Vol_Read_16(Address : Signed_64) : Unsigned_16Vol_Write_16(Address : Signed_64, Value : Unsigned_16)
32-Bit (Word)Vol_Read_32(Address : Signed_64) : Unsigned_32Vol_Write_32(Address : Signed_64, Value : Unsigned_32)
64-Bit (Double-Word)Vol_Read_64(Address : Signed_64) : Unsigned_64Vol_Write_64(Address : Signed_64, Value : Unsigned_64)

Command-line interface (CLI) reference

The loom Workspace Tool

Command / FlagDescription

loom build [--release] [--opt-report] [--verbose]Compiles all sources and links the native executable or bare-metal ELF/UF2.

Formal EBNF grammar specification

ModuleDecl     ::= "Module" Identifier
TopLevel       ::= ModuleDecl ( ImportDecl | UseDecl | BlockDecl | EnumDecl | RecordDecl | ExternBlock )*

ImportDecl     ::= "Import" Identifier
UseDecl        ::= "use" Identifier

EnumDecl       ::= "Enum" Identifier ":" Type ( Identifier "=" IntegerLiteral )+ "End" Identifier
RecordDecl     ::= "Record" Identifier ( Identifier ":" Type )+ "End" Identifier

BlockDecl      ::= "Block" Identifier
                   [ "Takes" ( Identifier ":" Type )+ ]
                   ( "Produces" Type [ "Declares" VarDecl* ] "Implements" Statement* "End" Identifier
                   | "Produces" "(" Expression ")" "End" Identifier
                   | [ "Declares" VarDecl* ] "Implements" Statement* "End" Identifier )

VarDecl        ::= Identifier ":" [ "Constant" ] Type [ "=" Expression ]

Statement      ::= Assignment
                 | CompoundAssign
                 | CallStmt
                 | WriteStmt
                 | IfStmt
                 | LoopStmt
                 | MatchStmt
                 | EnsureStmt
                 | "Exit"
                 | "Skip"
                 | "Give" Expression

CompoundAssign ::= LValue ( "+=" | "-=" | "*=" | "/=" | "&=" | "|=" | "^=" ) Expression
LoopStmt       ::= "Loop" [ ( "while" | "until" ) Expression ] Statement* "End" "Loop"

MatchStmt      ::= "Match" Expression ( "When" Expression ":" Statement* )+ [ "Else" ":" Statement* ] "End" "Match"
EnsureStmt     ::= "Ensure" "{" Statement "}"
CallStmt       ::= [ Identifier "." ] Identifier "(" [ Expression ( "," Expression )* ] ")"
WriteStmt      ::= "Write" "(" [ Expression ( "," Expression )* ] ")" | "Write_UART" "(" Expression ")"
