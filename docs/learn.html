Loom

Learn Loom

A complete, beginner-friendly tour of the Loom systems programming language. Every lesson is an executable, standalone program.

1 · Program Structure & Hello, World

Every Loom source file begins with a Module declaration naming the module. Program execution begins at Block Main. Statements are written inside an Implements block, and every block closes with End Name. The Print built-in writes text followed by a newline to standard output. Characters following # are comments.

Module Main

Block Main
Implements
    Print("Hello, Loom!")   # Standard output print
End Main

2 · Primitive Data Types & Variables

Loom provides explicit, fixed-width numeric and scalar types. Variables are declared inside the Declares section of a block. Uninitialized variables are automatically zero-initialized, or you can provide an initial value. Loom disallows silent implicit conversions; converting between types is written explicitly with as.

TypeBit WidthExample Literals
Signed_8, 16, 32, 648 to 64 bits42, -100, 100_000
Unsigned_8, 16, 32, 648 to 64 bits0xFF, 0b1010, 255
Float_32, Float_6432 or 64 bits3.14159, -0.5
Boolean1 bitTrue, False
Character32-bit Unicode'A', '\n', 'é'
StringUTF-8 text"Hello <Name>"

Strings support inline interpolation via <Expr>, including optional formatting flags like <Value:.2f> (two decimal places) or <Hex:04X> (4-digit uppercase hexadecimal).

Module Main

Block Main
Declares
    Age : Signed_32 = 25
    Count : Unsigned_64 = 1000
    Price : Float_64 = 19.99
    Active : Boolean = True
    Grade : Character = 'A'
    Name : String = "Loom"
Implements
    Print("<Name>: Age <Age>, Price $<Price:.2f>, Grade <Grade>, Active=<Active>")
End Main

3 · Operators & Expressions

Loom supports a full set of arithmetic, bitwise, comparison, and logical operators. Integer arithmetic is automatically safety-checked against overflow.

CategoryOperators
Arithmetic+, -, *, /, Mod, pow
Bitwise& (AND), | (OR), ^ (XOR), ~ (NOT), LSL, LSR
Comparison==, !=, <, <=, >, >=
LogicalAnd, Or, Not
Compound+=, -=, *=, /=, &=, |=
Module Main

Block Main
Declares
    A : Signed_32 = 14
    B : Signed_32 = 4
    BitA : Unsigned_32 = 0b0011
    BitB : Unsigned_32 = 0b0101
Implements
    Print(A + B)       # 18
    Print(A - B)       # 10
    Print(A * B)       # 56
    Print(A / B)       # 3
    Print(A Mod B)     # 2
    Print(BitA & BitB)  # 1
    Print(BitA | BitB)  # 7
    Print(BitA ^ BitB)  # 6
    Print(BitA LSL 2)  # 12
End Main

4 · Conditionals & Pattern Matching

Branches are evaluated using If, Else If, and Else blocks, concluding with End If. For multi-way branching, Loom provides Match, which matches discrete values or closed ranges (Low .. High) with an optional Default fallback branch.

Module Main

Block Main
Declares
    Score : Signed_32 = 85
Implements
    If Score >= 90
        Print("Grade: A")
    Else If Score >= 80
        Print("Grade: B")
    Else
        Print("Grade: C")
    End If

    Match Score
        When 90 .. 100:
            Print("Outstanding")
        When 80 .. 89:
            Print("Great work")
        Default:
            Print("Keep going")
    End Match
End Main

5 · Loops & Iteration (All 4 Forms)

Loom provides four distinct looping mechanisms for every iteration scenario.

5.1 Infinite Loop with Exit and Skip

An unconditional loop that runs until Exit is called. Skip skips the rest of the current iteration and jumps to the next cycle.

Module Main

Block Main
Declares
    I : Signed_32 = 0
Implements
    Loop
        I += 1
        If I == 2
            Skip       # Skips printing 2
        End If
        If I > 4
            Exit       # Terminates the loop
        End If
        Print(I)
    End Loop
End Main

5.2 While Loop (Loop while)

Tests a condition at the top of the loop and executes as long as the condition evaluates to True.

Module Main

Block Main
Declares
    Count : Signed_32 = 1
Implements
    Loop while Count <= 3
        Print(Count)
        Count += 1
    End Loop
End Main

5.3 Until Loop (Loop until)

Executes as long as the condition evaluates to False, terminating as soon as the condition becomes True.

Module Main

Block Main
Declares
    Step : Signed_32 = 1
Implements
    Loop until Step > 3
        Print(Step)
        Step += 1
    End Loop
End Main

5.4 For-In Loop (Ranges & Collections)

Iterates cleanly over numeric ranges (1 .. N) or collection elements with value binding or index-value pair binding (Loop Idx, Val in Arr).

Module Main

Block Main
Declares
    Arr : Signed_32 Array[3] = {10, 20, 30}
Implements
    # Range iteration
    Loop N in 1 .. 3
        Print(N)
    End Loop

    # Collection element and index iteration
    Loop Idx, Val in Arr
        Print("Item <Idx>: <Val>")
    End Loop
End Main

6 · Procedures (Blocks)

Functions without a return value are procedural blocks. Parameters are declared following the Takes keyword. Parameter types are strictly enforced.

Module Main

Block Greet
Takes
    Name : String
    Times : Signed_32
Declares
    I : Signed_32 = 0
Implements
    Loop while I < Times
        Print("Welcome, <Name>!")
        I += 1
    End Loop
End Greet

Block Main
Implements
    Greet("Loom Developer", 2)
End Main

7 · Giving Blocks & Multiple Returns (Tuples)

Blocks that produce a return value declare Produces <Type> and return results via the Give keyword. Loom also supports lightweight tuples for multiple return values with destructuring assignment.

Module Main

Block MinMax
Takes
    A : Signed_32
    B : Signed_32
Produces (Signed_32, Signed_32)
Implements
    If A <= B
        Give (A, B)
    Else
        Give (B, A)
    End If
End MinMax

Block Main
Declares
    Lo : Signed_32
    Hi : Signed_32
Implements
    Lo, Hi = MinMax(42, 17)   # Tuple unpacking assignment
    Print("Low: <Lo>")
    Print("High: <Hi>")
End Main

7.1 · Omitting Empty Sections & Concise Giving Blocks

To reduce boilerplate, Loom allows you to completely omit empty sections:

  • Omit Takes: When a procedure or function takes no parameters.
  • Omit Declares: When a block declares no local variables.
  • Omit Produces: When a block returns no value (procedural blocks).
  • Omit Implements and Give: Single-expression giving blocks can write their return expression directly on the Produces line, completely omitting Implements and Give:
Block Double
Takes
    Num : Signed_32
Produces Num * 2
End Double

The following example shows how omitting Takes, Declares, Implements, and Produces keeps Loom code clean and minimal:

Module Main

# 1. Omits Takes, Declares, and Produces (simple void procedure)
Block Greet Implements
    Print("Welcome to Loom!")
End Greet

# 2. Concise Giving Block: Omits Declares, Implements, and Give
Block Double
Takes
    Num : Signed_32
Produces Num * 2
End Double

# 3. Omits Declares: Takes arguments and gives a result directly
Block Add
Takes
    A : Signed_32
    B : Signed_32
Produces Signed_32
Implements
    Give A + B
End Add

# 4. Omits Takes and Produces: Entry point with Declares and Implements
Block Main Declares
    Value : Signed_32 = 21
Implements
    Greet()
    Print("Double: <Double(Value)>")
    Print("Sum: <Add(10, 32)>")
End Main

8 · Records & Data Structures

A Record defines a custom composite data type with named, typed fields. Records are value types copied on assignment. You can instantiate records field-by-field or using structured record literals RecordName{ Field: Val }.

Module Main

Record Point
    X : Signed_32
    Y : Signed_32
End Point

Block Main
Declares
    P : Point
    Origin : Point
Implements
    P.X = 10
    P.Y = 25
    Origin = Point{ X: 0, Y: 0 }
    Print("Point: (<P.X>, <P.Y>)")
    Print("Origin: (<Origin.X>, <Origin.Y>)")
End Main

9 · Records with Drop (RAII Destructors)

Loom supports deterministic resource management without a garbage collector. By defining an optional Drop block inside a Record, the compiler guarantees that the cleanup code executes automatically whenever the record variable goes out of scope — including early block exits.

Module Main

Record SafeBuffer
    Ptr : Signed_32 Pointer
Drop
    If Ptr != Null
        Release(Ptr)
        Print("SafeBuffer released automatically")
    End If
End SafeBuffer

Block ProcessBuffer
Declares
    Buf : SafeBuffer
Implements
    Buf.Ptr = Allocate(16)
    Print("Processing data inside buffer")
    # Buf is dropped and freed here automatically!
End ProcessBuffer

Block Main
Implements
    ProcessBuffer()
End Main

10 · Collection Types

Loom provides a comprehensive suite of collection types tailored for systems development. All collections use 1-based indexing.

10.1 Fixed Arrays (T Array[N])

Stack-allocated fixed-size buffers with compile-time bounds and a .Length property.

Module Main

Block Main
Declares
    Arr : Signed_32 Array[4] = {5, 10, 15, 20}
Implements
    Arr[1] = 99
    Print(Arr[1])
    Print(Arr.Length)
End Main

10.2 Slices (T Slice)

Non-owning views into continuous memory. Slices can be created from arrays or vectors using range notation Arr[Start .. End].

Module Main

Block Main
Declares
    Arr : Signed_32 Array[5] = {10, 20, 30, 40, 50}
    Part : Signed_32 Slice
Implements
    Part = Arr[2 .. 4]   # Elements 2, 3, and 4
    Print(Part[1])       # 20
    Print(Part.Length)   # 3
End Main

10.3 Dynamic Vectors (T Vector)

Growable heap-allocated arrays. Append elements dynamically with .Push(item).

Module Main

Block Main
Declares
    Vec : Signed_32 Vector[0]
Implements
    Vec.Push(100)
    Vec.Push(200)
    Print(Vec[1])        # 100
    Print(Vec.Length)    # 2
End Main

10.4 Dynamic Text (Text)

Mutable string buffers supporting fast dynamic concatenation via +=.

Module Main

Block Main
Declares
    Txt : Text
Implements
    Txt += "Loom "
    Txt += "Language"
    Print(Txt)           # Loom Language
    Print(Txt.Length)    # 13
End Main

10.5 Hash Maps (HMap[K : V])

Fast associative open-addressing hash table supporting typed keys and values.

Module Main

Block Main
Declares
    Scores : HMap[String : Signed_32]
Implements
    Scores["Alice"] = 95
    Scores["Bob"] = 88
    Print(Scores["Alice"])
    Print(Scores.Length)
End Main

11 · Pointers & Memory Addresses

Loom provides raw pointer capabilities for systems programming. Obtain addresses using Address(Variable), dereference with Deref(Ptr), or index into memory with Ptr[Index]. Unassigned pointers are equal to Null.

Module Main

Block Main
Declares
    Num : Signed_32 = 100
    Ptr : Signed_32 Pointer
Implements
    Ptr = Address(Num)
    Print(Deref(Ptr))   # Reads 100
    Ptr[1] = 250        # Mutates Num directly
    Print(Num)          # Prints 250
End Main

12 · Dynamic Memory Allocation

Manual heap memory management is explicit through Allocate(count), Resize(ptr, count), and Release(ptr). Pair allocations with an Ensure { ... } block to guarantee cleanup when the enclosing block terminates.

Module Main

Block Main
Declares
    Memory : Signed_32 Pointer
Implements
    Memory = Allocate(8)
    Ensure {
        Release(Memory)
        Print("Memory cleaned up")
    }
    Memory[1] = 1234
    Print(Memory[1])
End Main

13 · Tasks & Multithreading

Concurrency is built directly into Loom. The Spawn keyword launches a function asynchronously on an OS thread pool, returning a typed Task_Handle. Calling Join halts until the task finishes and returns the produced value.

Module Main

Block ComputeWorker
Takes
    Base : Signed_32
Produces Signed_32
Implements
    Give Base * 2
End ComputeWorker

Block Main
Declares
    Handle : Signed_32 Task_Handle
    Answer : Signed_32
Implements
    Handle = Spawn ComputeWorker(21)
    Answer = Join Handle
    Print(Answer)       # 42
End Main

14 · Asynchronous Programming (Async / Await)

Loom provides first-class asynchronous routines declared with Async Block. Calling an async block yields a Future[T]. Use Await to suspend and retrieve the completed value.

Module Main

Async Block AsyncFetch
Takes
    Value : Signed_32
Produces Signed_32
Declares
    Result : Signed_32
Implements
    Result = Value * 10
    Give Result
End AsyncFetch

Block Main
Declares
    Fut : Future[Signed_32]
    Result : Signed_32
Implements
    Fut = AsyncFetch(5)
    Result = Await Fut
    Print(Result)       # 50
End Main

15 · Error Handling & Modules

Functions that may fail declare error unions with Produces Type or ErrorEnum. Inside functions that produce errors, try unwraps the value or immediately returns the error. Multi-file projects organize code using Module, Import, and use.

Module Main

Enum MathError : Signed_32
    DivZero = 1
End MathError

Block Divide
Takes
    A : Signed_32
    B : Signed_32
Produces Signed_32 or MathError
Implements
    If B == 0
        Give MathError.DivZero
    End If
    Give A / B
End Divide

Block Calculate
Produces Signed_32 or MathError
Declares
    Val : Signed_32
Implements
    Val = try Divide(100, 4)
    Give Val + 5
End Calculate

Block Main
Declares
    Res : Signed_32 or MathError
Implements
    Res = Calculate()
    Print("Calculation finished successfully")
End Main

16 · Embedded RP2040 & Bare-Metal Hardware

Loom provides a dedicated bare-metal toolchain for microcontroller platforms such as the Raspberry Pi Pico (RP2040). There is no operating system overhead: execution starts directly from the second-stage bootloader and runs in Thumbv6-M machine code. Core hardware modules such as Gpio, Time, Usb_Cdc, and Sync are built directly into the standard library with zero imports required.

16.1 Hardware GPIO & USB-CDC Serial

Microcontroller pins are managed via Gpio. Pins can be initialized with Gpio.Init_Output(Pin), driven with Gpio.Write(Pin, State), Gpio.High(Pin), Gpio.Low(Pin), or toggled via Pin.Toggle. High-speed serial text transmission without external UART adapters is achieved with Usb_Cdc and the native Print built-in:

Module Main

Block Main
Declares
    LED_PIN : Constant Gpio.Pin = Gpio.PICO_LED_PIN
    Tick : Unsigned_32 = 0
Implements
    Gpio.Init_Output(LED_PIN)
    Time.Sleep_MS(500)
    Print("Raspberry Pi Pico initialized!\n")

    Loop
        LED_PIN.Toggle
        Tick = Tick + 1
        If Usb_Cdc.Is_Configured()
            Print("Blink tick=\n")
        End If
        Time.Sleep_MS(500)
    End Loop
End Main

16.2 Programmable I/O (PIO) DSL

The RP2040 includes two PIO blocks with four independent state machines each. Loom includes a dedicated DSL for PIO assembly that lowers directly into 16-bit state-machine instructions:

Pio_Program SquareWave
    Wrap_Target
        Set(Pins, 1) [1]
        Set(Pins, 0) [1]
    Wrap
End Pio_Program

Block RunPio Takes Sm : Pio_State_Machine Implements
    Pio.Sm_Init(Sm, SquareWave)
    Pio.Sm_Set_Enabled(Sm, True)
End RunPio

16.3 Dual-Core Multicore Execution

RP2040 features two ARM Cortex-M0+ cores. Core 1 can be launched with a single block reference, exchanging data via hardware FIFOs:

Module Main

Block Core1_Worker Implements
    Loop
        Val = Multicore.Fifo_Pop()
        Print("Core 1 received: <Val>\n")
    End Loop
End Core1_Worker

Block Main Implements
    Multicore.Launch_Core1(Core1_Worker)
    Multicore.Fifo_Push(42)
    Multicore.Fifo_Push(100)
End Main
