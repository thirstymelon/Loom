RP2040 Beginner Tutorials

A complete, beginner-friendly guide to bare-metal embedded programming on the Raspberry Pi Pico with Loom. Every hardware peripheral, function, and operation explained with runnable code examples.

Architecture & Zero-Imports Standard Library

Loom's RP2040 toolchain compiles directly to bare-metal ARM Cortex-M0+ (Thumbv6-M) machine code with zero operating system overhead. In the RP2040 toolchain, all core hardware modules are built into the standard library and available with zero imports: Gpio, Time, Usb_Cdc, Uart, Spi, I2c, Pwm, Adc, Dma, Watchdog, Rtc, Multicore, Sync, Sio, Pio, and System. You never need to write Import Gpio or Import Time.

1 · GPIO Pin Control

The Gpio module controls the 30 multi-function General Purpose I/O pins of the RP2040 (GPIO 0 through 29). The onboard Raspberry Pi Pico LED is pin 25 (Gpio.PICO_LED_PIN).

1.1 Configuring Outputs & Blinking (Toggle)

Initialize a pin as an output using LED.Init_Output(). Toggle the output level with LED.Toggle():

Module Main

Block Main
Declares
    LED : Constant Gpio.Pin = Gpio.PICO_LED_PIN
Implements
    LED.Init_Output()
    Loop
        LED.Toggle()
        Time.Sleep_MS(500)
    End Loop
End Main

1.2 Driving Output State (High, Low, Write)

Set a pin's state explicitly with clean dot notation: Pin.High(), Pin.Low(), or Pin.Write(Boolean):

Module Main

Block Main
Declares
    Pin16 : Constant Gpio.Pin = Gpio.Pin_16
Implements
    Pin16.Init_Output()
    Pin16.High()
    Time.Sleep_MS(250)
    Pin16.Low()

1.3 Reading Inputs with Pull-Up / Pull-Down

Initialize inputs with internal bias resistors using Button.Init_Input(Pull) where pull mode is Gpio.Pull.Up, Gpio.Pull.Down, or Gpio.Pull.None. Read the digital pin state with Button.Read():

Module Main

Block Main
Declares
    Button : Constant Gpio.Pin = Gpio.Pin_15
    State : Boolean
Implements
    Button.Init_Input(Gpio.Pull.Up)
    Loop
        State = Button.Read()
        If Not State
            Print("Button Pressed (Active Low)!\n")
        End If
        Time.Sleep_MS(100)
    End Loop
End Main

3 · USB-CDC Serial Console & Print

The RP2040 hardware runtime includes built-in TinyUSB-compatible CDC serial support. Print(...) automatically routes through USB-CDC serial out of the box when connected to your computer.

3.1 Checking USB Connection & Writing Text

Module Main

Block Main
Declares
    Count : Unsigned_32 = 0
Implements
    Loop
        If Usb_Cdc.Is_Configured()
            Print("USB connected! Iteration=\n")
        End If
        Count = Count + 1
        Time.Sleep_MS(1000)
    End Loop
End Main

3.2 Reading Incoming Bytes over USB

Module Main

Block Main
Declares
    Byte_In : Signed_32
Implements
    Loop
        If Usb_Cdc.Available() > 0
            Byte_In = Usb_Cdc.Read_Byte()
            If Byte_In >= 0
                Usb_Cdc.Write_Byte(Byte_In as Unsigned_8)
            End If
        End If
        Time.Sleep_MS(10)
    End Loop
End Main

3.3 Routing Print Output (USB vs UART)

Control where standard output goes using Usb_Cdc.Set_Output_Sink(Sink) with Output_Sink.USB, Output_Sink.UART0, Output_Sink.UART1, or Output_Sink.None:

Block Main
Implements

4 · Hardware UART Serial

RP2040 features two independent hardware UART controllers (Uart0 and Uart1). Standard pins are GPIO 0 (TX) and GPIO 1 (RX) for UART0.

4.1 Initializing UART & Sending Strings

Module Main

Block Main
Declares
    Dev : Uart.Uart_Device or Uart.Uart_Error
    Uart0 : Uart.Uart_Device
Implements
    Dev = Uart.Init(Uart.Uart_Port.UART0, Gpio.Pin_0, Gpio.Pin_1, 115200)
    If (Dev as Uart.Uart_Device)
        Uart0 = Dev as Uart.Uart_Device
        Uart0.Write_Str("Loom Hardware UART0 Ready\r\n")
    End If
End Main

4.2 Polling for Incoming Data

Module Main

Block Main
Declares
    Dev : Uart.Uart_Device = Uart.UART_0
    Ch : Unsigned_8
Implements
    Loop
        If Dev.Is_Readable()
            Ch = Dev.Read_Byte()
            Dev.Write_Byte(Ch)
        End If
        Time.Sleep_MS(5)
    End Loop
End Main

10 · Hardware Watchdog Timer

Automatically reset the microcontroller if software hangs or locks up in an unexpected state.

10.1 Enabling and Feeding the Watchdog

Module Main

Block Main
Implements
    If Watchdog.Caused_Reboot()
        Print("Reboot was triggered by Watchdog!\n")
    End If

    # Enable watchdog with 2000 ms timeout
    Watchdog.Enable(2000, False)

    Loop
        # Do periodic work
        Time.Sleep_MS(500)
        # Feed watchdog to reset timer
        Watchdog.Feed()
    End Loop
End Main

15 · Programmable I/O (PIO) DSL

Loom provides a native DSL for writing custom hardware protocols (I2S, WS2812B LEDs, VGA, UART) using the RP2040's 8 independent state machines.

Pio_Program SquareWave
    Wrap_Target
        Set(Pins, 1) [1]
        Set(Pins, 0) [1]
    Wrap
End Pio_Program

Block Main
Declares
    Sm : Pio.State_Machine
Implements

    Sm.Set_Clkdiv(1, 0)

    Sm.Put(42)
End Main

17 · Building & Flashing

loom new --rp2040 my_firmware

loom build
