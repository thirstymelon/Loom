Getting started

From install to a running program in a few minutes.

Install

Loom ships with pre-built macOS Apple Silicon installer packages (.pkg):

  • Loom-1.5.0-macos-arm64-native.pkg: Loom Native Desktop Toolchain (CLI, compiler, standard library, runtime).
  • Loom-1.5.0-macos-arm64-rp2040.pkg: Loom RP2040 Embedded Bare-Metal Toolchain (ARM Cortex-M0+ compiler, SDK, UF2 generator).

You can also install toolchains on demand using the loom CLI:

loom get toolchain rp2040    # download and register RP2040 toolchain
loom set toolchain rp2040    # switch active default toolchain
loom toolchains              # list installed toolchains

Your first native project

loom new hello
cd hello
loom run

A project is a folder with a config.toml and sources in src/. Every file begins with a Module line, and execution starts at Block Main.

Module Main

Block Main
Implements
    Print("Hello, Loom")
End Main

Your first RP2040 embedded project

Scaffold a specialized embedded bare-metal project targeting the Raspberry Pi Pico:

loom new --rp2040 blinky
cd blinky
loom build                   # compiles ARM Thumbv6-M binary & generates blinky.uf2
loom flash --monitor         # boots into BOOTSEL, writes UF2, & connects serial monitor

The scaffolded src/main.loom uses the RP2040 BSP and hardware GPIO modules:

Module Main

Import Gpio
Import Time
Import Usb_Cdc

Constant LED_PIN : Pin = 25

Block Main
Implements
    Gpio.Init(LED_PIN)
    Gpio.Set_Dir(LED_PIN, Gpio.DIR_OUT)
    Usb_Cdc.Init()

    Loop
        Gpio.Put(LED_PIN, 1)
        Print("LED On")
        Time.Sleep_Ms(500)

        Gpio.Put(LED_PIN, 0)
        Print("LED Off")
        Time.Sleep_Ms(500)
    End Loop
End Main

Everyday commands

CommandDoes
loom build [--release]Compile the project using the active or configured toolchain
loom runBuild and execute natively
loom flash [--monitor]Flash RP2040 UF2 over picotool or mass storage and attach monitor
loom monitor [--port <dev>]Open zero-dependency POSIX raw serial monitor (115200 baud)
loom get toolchain <tc>Fetch and install an official toolchain (e.g. rp2040)
loom set toolchain <tc>Set the active toolchain for the current workspace or globally
loom add <pkg>Add a package with SemVer constraint solving and SHA-256 locking
loom fmt [--check]Format sources canonically
loom testRun declared test blocks
loom graphEmit a call or data graph (Mermaid or JSON)
loom cleanDelete target/

Editor support

A VS Code extension is in the repository under vscode-loom/ as a ready-made .vsix: syntax highlighting, snippets, and compiler-backed diagnostics. The loom-lsp server provides hover, completion and go-to-definition.
