Getting started

From install to a running program in a few minutes.

Install

Loom ships as a fast, native toolchain. The macOS Apple Silicon installer (.pkg) and standalone tarballs are available on GitHub releases, and packages can be retrieved using the loom CLI.

loom new hello             # scaffold a new Loom project
cd hello
loom run                   # build and execute natively

Building from source requires CMake 3.20+ and LLVM. Check CMakeLists.txt and the release workflow for the exact setup.

Your first project

loom new hello
cd hello
loom run

A project is a folder with a config.toml and sources in src/. Every file begins with a Module line, and execution starts at Block Main.

Module Main

Block Main
Implements
    Print("Hello, Loom")
End Main

Everyday commands

CommandDoes
loom build [--release]Compile the project
loom runBuild and execute
loom get <library>Download and install an ecosystem library
loom fmt [--check]Format sources canonically
loom testRun declared test blocks
loom graphEmit a call or data graph (Mermaid or JSON)
loom cleanDelete target/

Editor support

A VS Code extension is in the repository under vscode-loom/ as a ready-made .vsix: syntax highlighting, snippets, and compiler-backed diagnostics. The loom-lsp server provides hover, completion and go-to-definition.
