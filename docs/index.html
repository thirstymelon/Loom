Loom

Loom

A statically typed systems language with readable block syntax, an LLVM backend, and predictable memory safety.

Loom aims at the space between C and high-level languages: fixed-width types, no implicit conversions, no garbage collector, and direct hardware-level control, written in keywords you can read aloud. One compiler targets native desktop and systems applications.

Design principles

Explicit types

Integers, floats, pointers and slices have fixed widths. Conversions are written out with as, Cast[T] or T(x).

Predictable memory

Stack values, fixed arrays, non-owning slices and raw pointers. Heap use is explicit through Allocate, Resize and Release, and Ensure gives deterministic cleanup.

Readable syntax

Blocks open with a keyword and close with End Name. Indexing is 1-based, with bounds checks that the optimizer removes where it can prove them.

Systems performance

Volatile pointers, Packed Record layouts, native compilation, and direct hardware-level memory control.
