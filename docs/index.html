Core language pillars

Loom combines the readability of human language with the raw precision of low-level machine execution. It was designed from first principles around five immutable engineering pillars:

PillarTechnical Specification & Guarantees
ReadabilityStrictly capitalized keywords, explicit block delimiters (Block / End <Name>), and direct procedure calls (Add(1, 2)). Statements read like structured English without punctuation noise.
Zero-Cost ControlNo garbage collector, no background runtime threads, and no hidden heap allocations. You work directly with raw typed pointers, fixed contiguous memory, hardware registers, and bare-metal targets.
Deterministic CleanupThe Ensure { <statement> } construct executes cleanup logic in strict last-in, first-out (LIFO) reverse order upon leaving a block or procedure, guaranteeing deterministic resource teardown on every exit path.
One-Based IndexingArrays, slices, and strings are 1-indexed. Index 1 is the first element, and Arr[Arr.Length] is the last element. Dynamic out-of-bounds accesses trap deterministically at runtime.
Native LLVM BackendThe loomc compiler lowers Loom code directly into optimized LLVM Intermediate Representation (IR), applying aggressive optimizations (-O3, dead-code elimination, loop vectorization, function inlining) and linking with Clang.

Modern language capabilities

Loom v1.1.0 brings an expressive set of modern language features designed for systems engineers and application developers:

1. Concise Routine Signatures

When a block implementation consists of a single return expression, Loom provides a clean, concise signature that eliminates boilerplate while retaining full type safety:

Block Add
    Takes
        A : Signed_32
        B : Signed_32
    Produces (A + B)
End Add

2. Pattern Matching

Multi-way branch matching using Match, When, and Else clauses:

Match Mode
    When Mode.Idle:
        Sleep()
    When Mode.Active:
        Process()
    Else:
        Fault()
End Match

3. Compound Assignment Operators

Direct in-place mutation operators: +=, -=, *=, /=, &=, |=, and ^=.

Total += Value
Flags &= ~0x01
Mask |= (1 LSL Pin)

4. Three Explicit Loop Constructs

Loom provides an infinite loop and two conditional loops, alongside Exit (break) and Skip (continue):

# Conditional while loop
Loop while (Count < 10)
    Count += 1
End Loop

# Conditional until loop
Loop until (Count >= 10)
    Count += 1
End Loop

# Infinite loop with early exit
Loop
    If Finished
        Exit
    End If
End Loop

5. Composite Records & Initialization

Record Point
    X : Signed_32
    Y : Signed_32
End Point

Block Main
Declares
    Pos : Point = Point{ X: 10, Y: 20 }
Implements
    Pos.X += 5
    Write("Pos: (<Pos.X>, <Pos.Y>)")
End Main

6. Raw Memory Pointers & Deterministic Ensure

Block Worker
Declares
    Val : Signed_32 = 42
    Ptr : Signed_32 Pointer = Address(Val)
Implements
    Ensure { Write("Cleanup executed in reverse order!") }
    Deref(Ptr) = 100
    Write(Val)
End Worker

Quick start

Scaffolding, compiling, and running a new Loom native application requires only three commands using the workspace tool:

loom new Hello
cd Hello
loom run
