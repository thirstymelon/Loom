Interactive Curriculum

Learn Loom by writing it.

A structured, hands-on path through systems programming in Loom. Each lesson covers language mechanics, code examples, common pitfalls, and practical exercises with solutions. Your progress is saved automatically in this browser.

How to follow this path: Create a playground workspace with loom new LearningLoom, open src/main.loom in your editor, and run each exercise with loom run.

  1. 1. Hello, World & Program Structure

    Understand the Module declaration, executable Block Main entry point, the Implements section, and the Write(...) intrinsic with newline semantics.

  2. 2. Variables, Types & Literals

    Master explicit integer bitwidths (Signed_8..Signed_64, Unsigned_8..Unsigned_64), floats, booleans, Unicode characters, digit separation (100_000), binary (0b0100), hex (0xAF), Block Global, and string interpolation.

  3. 3. Operators & Compound Assignments

    Arithmetic, bitwise shifts and masks (&, |, ^, ~, LSL, LSR), modulo (Mod), logical operators (And, Or, Not), and compound assignments (+=, -=, *=, /=, &=, |=, ^=).

  4. 4. Conditional Decisions

    Branching logic using If, multiple Else If clauses, fallback Else blocks, and strict End If delimiters.

  5. 5. Loops & Iteration Control

    The three loop forms: infinite Loop, conditional Loop while <cond>, and Loop until <cond>. Breaking out with Exit and continuing with Skip.

  6. 6. Procedures, Parameters & Concise Routines

    Defining input parameters with Takes, specifying return types with Produces, returning values with Give, and writing single-line concise routines (Produces (A + B)).

  7. 7. Records, Enums & Pattern Matching

    Structured composite data with Record, modern struct initialization (Point{ X: 10, Y: 20 }), strongly typed Enum declarations, and expressive multi-branch Match ... When statements.

  8. 8. Arrays, Slices & One-Based Indexing

    Fixed stack arrays (T Array[N]), fat pointer non-owning views (T Slice), 1-based indexing semantics (Arr[1] to Arr[Arr.Length]), and runtime bounds-trapping guarantees.

  9. 9. Raw Pointers, Cast & Deterministic Ensure

    Low-level memory control with T Pointer, address-of (Address), dereferencing (Deref), the Null literal, type conversions (Cast), and deterministic LIFO cleanup with Ensure { <stmt> }.

  10. 10. Multi-File Modules & Namespaces

    Structuring multi-file codebases with Module <Name>, importing files with Import, calling qualified procedures (Math.Add), and eliminating namespace prefixes using use.
